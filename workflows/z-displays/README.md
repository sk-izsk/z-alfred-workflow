# Displays for Alfred 6

Change display resolution and refresh rate, the main display and mirroring in a native Alfred window,
and switch Dark Mode.

Requires macOS 13+, Alfred 6 with Powerpack and Node.js 22+ or Bun. Nothing else to install.

## Open

Type `displays`, or choose Displays in Swiss. Each display shows its resolution and refresh rate; the
main display (the one with the menu bar) comes first.

## Actions

- **↩** on a display lists its resolutions, largest first, with refresh rate, **HiDPI**, **Native** and
  **Current**. Type to filter (`1080 120`, `hidpi`, `native`). **↩** on a resolution applies it.
- **⌘Z** undoes the last resolution change.
- **⌘M** makes the selected display the main display.
- **⌘D** turns Dark Mode on or off (macOS asks once to let Alfred control System Events).
- **⌘K**: Show Resolutions, Undo, Make Main Display, Mirror the Main Display or Stop Mirroring, Dark
  Mode, Open Displays Settings, Refresh and Configuration.
- **Back** (Hyper+B) returns from the resolutions to the displays, then to Swiss or Alfred's search.

## How it works

- Displays come straight from macOS (CoreGraphics) through a small JavaScript for Automation script
  that ships with the workflow: no helper app, about 0.15 s per list.
- Changes are saved the way Displays settings saves them, so they stay after a restart.
- Only resolutions macOS marks as usable for the desktop are offered.
