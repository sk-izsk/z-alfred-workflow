# Drives for Alfred 6

See mounted drives and opened disk images with their free space, and eject them, in a native Alfred
window.

Requires macOS 13+, Alfred 6 with Powerpack and Node.js 22+ or Bun. Nothing else to install.

## Open

Type `drives`, or choose Drives in Swiss. The startup disk comes first, then internal, external, disk
images (DMGs, with their file name) and network shares, each with its format and free space. A drive
that is more than 90% full gets an orange icon. Type to filter (`dmg`, `external`, `apfs`, a name).

## Actions

- **↩** ejects the drive; on the startup disk and other internal drives it opens them in Finder.
- **⌘O** opens the drive in Finder, **⌘E** ejects, **⌘C** copies its path.
- **⌘K**: Eject, Force Eject, Open in Finder, Show Disk Image File, Copy Path, Eject All, Open Disk
  Utility, Refresh and Configuration. Force Eject and Eject All ask first.
- **Back** (Hyper+B) returns to Swiss when opened there, otherwise to Alfred's search.

When a drive can't be ejected because something is using it, Drives names the app holding it.

## How it works

- Volumes come from macOS directly (a small JavaScript for Automation script that ships with the
  workflow), and disk images from `hdiutil`, so a DMG shows even when it was opened hidden. The list
  loads in about 0.1 s.
- Ejecting uses `diskutil`, as Finder does: ejecting a disk ejects all its volumes. Network shares are
  unmounted.
