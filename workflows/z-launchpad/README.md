# Launchpad for Alfred 6

A Launchpad-style grid of your apps, based on Alfred's own
[Launchpad workflow](https://github.com/alfredapp/launchpad-workflow/), with the parts it can't do:
**swipe or scroll between pages**, and **folders you make by dragging**, then rename or delete.

Requires macOS, Alfred 6 with Powerpack and Node.js 22+ or Bun.

## Open

Type `launchpad`, or assign a Hotkey in the workflow (like the original). The grid shows your apps
7 × 5 per page with page dots below. The first time, it imports your order from the original
Launchpad workflow (read only), so everything stays where you put it.

## Pages

- **Swipe** sideways with two fingers on the trackpad; pages snap into place.
- **Scroll** the mouse wheel to go to the next or previous page.
- **⌘← / ⌘→**, **⌘1–⌘9**, or click a page dot.

## Folders

- **Create**: drag an app onto another and hold for a moment. The folder is named after the apps'
  App Store category (for example *Developer Tools*), like Launchpad.
- **Add**: drag an app onto a folder, or right-click → *Add to “…”*.
- **Open**: click it or press ↩. **Rename**: click the title in the open folder, type, press ↩.
- **Remove an app**: drag it out of the open folder, or right-click → *Remove from Folder*. A folder
  with one app left turns back into that app.
- **Delete**: right-click the folder → *Delete Folder*. Its apps go back into the grid.
- **Reorder**: drag an app between two others (a blue bar shows where). Hold at the left or right
  edge to move it to another page.

## Keyboard (as in the original)

Type to search (by name, word start or initials). Arrows move the selection, ↩ opens, ⌘C copies the
path, ⌥ + arrows shift an app, ⌘⌫ bumps it to the end, ⌘⌥← / ⌘⌥→ bump it to the previous / next
page, ⎋ closes a folder, the search or the window. **⌘?** shows every shortcut. Right-click an app
for *Open*, *Show in Finder* and *Copy Path*.

**Actions (⌘K)**: Cheat Sheet, Refresh Apps, Open Applications Folder, Reset Layout… and
Configuration. **Back** (Hyper+B) returns to Alfred's search.

## How it works

- Apps come from /Applications, /System/Applications and Safari's system folder (as in the original),
  plus any folders you add in Configuration. New apps appear at the end; removed apps disappear.
- Icons are saved as small images in the workflow's cache the first time (about 1 s for 200 apps).
- **Why a web view:** Alfred's native windows have no scroll, swipe or drag-and-drop events, so the
  grid is a local web page inside the window. It loads nothing from the internet. Each change you
  make (a drop, a rename) briefly reloads the grid to save it; the layout is kept in the workflow's
  data folder.
- The original Launchpad workflow uses the same keyword. Disable it in Alfred Preferences, or change
  one of the keywords.

## Development

```sh
bun install --frozen-lockfile
bun run check
bun run package
bun run link
```

Tests cover the layout rules (import, new and removed apps, page overflow, validation of changes).
The grid was exercised in a browser with real icons (paging, drag to folder, rename, delete, search,
keyboard); it has not yet been checked inside Alfred itself.
