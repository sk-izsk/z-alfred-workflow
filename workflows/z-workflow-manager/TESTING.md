# Verification

Automated checks cover numeric/datetime-style versions, bundle matching and alternate IDs, symlink-preserving removal target validation, release asset host boundaries, metadata cache/failure behavior, navigation protocol, native IDs, typing/filter state, configuration actions and removal review sheets.

Manual checks should cover Installed/Not Installed/Updates filters, query retention, ⌘K, Configuration, Swiss → Manager → Back, and the native installer queue. Do not remove user workflows or install updates merely to test the tool; use disposable workflows if mutation verification is needed.
