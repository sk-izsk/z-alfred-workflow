# Third-party notices

## Raycast Quick Calendar

The calendar icon (`assets/icons/calendar.png`, copied into the workflow and keyword icons) and
month/year navigation behavior come from **Quick Calendar**, authored by **fuksman**, with
contributors **pernielsentikaer** and **tonka3000**, in the Raycast Extensions repository.

Source: https://github.com/raycast/extensions/tree/e38232e713cc42a58cac81b8d3af9261fd1624e5/extensions/calendar

No Raycast runtime, React code, npm calendar library or weeknumber package is bundled. Date
arithmetic, the Alfred interface and the macOS Calendar bridge are implemented in this workflow.
