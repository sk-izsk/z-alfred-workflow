# Dev Servers for Alfred 6

Local development servers grouped by project, with their URL, framework and uptime; open, stop or
restart them.

Requires macOS, Alfred 6 with Powerpack and Node.js 22+ or Bun.

## Open

Type `devservers`, or choose Dev Servers in `dev`. Lists TCP listeners owned by recognised development
runtimes, grouped by project folder with counts, localhost ports, uptime and framework badges.
Search projects, tools and ports, or filter by framework. Heading rows are skipped by the arrow keys.

## Actions

- **↩** opens the localhost URL.
- **⌘K**: Stop Server, Copy URL, Restart Server, Open in Terminal, Show in Finder, Stop All for
  Project, Refresh, Pause/Resume, Stop All Listed Servers and Configuration.
- **Back** (Hyper+B) returns to the Dev launcher with its previous search and selection.

## Stopping and restarting

- **Stop** sends SIGTERM after checking again that the PID, start time, command, folder and port still
  match. **Stop All for Project** uses the selected project's folder; **Stop All Listed Servers** only
  the servers currently shown. Bulk actions never include processes that appeared later.
- **Restart** finds a `dev`, `start` or `develop` script in `package.json`, detects npm, pnpm, Yarn or
  Bun from the lockfile, checks the plan, then stops the server and starts it again in your terminal
  (so login prompts and output stay visible). Non-JavaScript servers can be stopped but must be
  started again in their own terminal.
- Restricted processes may be missing. This lists development runtimes, not every system service.
- The list refreshes every 5 seconds while open (2–60 seconds, or pause in ⌘K).

## Terminal

Terminal actions use **Terminal application** in Configuration: Ghostty, Terminal, iTerm2, kitty,
WezTerm, Alacritty or a custom command (a JSON array with `{command}` and `{cwd}`). Ghostty uses its
AppleScript API; macOS may ask for Automation permission. Nothing is installed automatically.

## Development

```sh
bun install --frozen-lockfile
bun run check
bun run package
bun run link
```
