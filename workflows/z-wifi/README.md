# Wi-Fi for Alfred 6

Current, nearby and saved Wi-Fi networks, with connect, disconnect and power controls, in a native
Alfred window.

Requires macOS, Alfred 6 with Powerpack and Node.js 22+ or Bun.

## Open

Type `wifi`, or choose Wi-Fi in `dev`. Rows show connection state, security and signal/noise when
available. Filter **All**, **Connected** or **Disconnected**.

## Actions

- **↩** disconnects the current network, or connects to a saved one using the password macOS already
  has. New networks and passwords go through Wi-Fi Settings; this workflow never stores a password.
- **⌘K**: Connect Saved Network / Disconnect, Copy Network Name, Copy Network Data, Show Saved
  Password, Refresh, Pause/Resume, Turn Wi-Fi On/Off, Wi-Fi Settings and Configuration.
- **Back** (Hyper+B) returns to the Dev launcher with its previous search and selection.

## Refresh

The full network scan (`system_profiler`) takes several seconds, so it runs when the window opens, on
**Refresh** (⌘R) and at most once a minute. In between, the timed refresh (every 10 seconds, 2–60 in
Configuration) only checks Wi-Fi power and the current connection, which takes milliseconds.

## Privacy

- **Show Saved Password** asks the Keychain for the saved network password (macOS may ask you to
  allow it) and shows it in a temporary dialog. It is never put in the window's data, session files,
  logs or the clipboard. If access is cancelled or denied you see a general error; Apple's Passwords
  app shows passwords the Keychain won't.
- macOS can hide network names. A connected network with a hidden name is labelled as such, never
  guessed; the current connection is cross-checked with `ipconfig`.

## Notes

- Nearby networks come from the system report (a CoreWLAN scan crashed in testing and isn't used).
  Disconnect uses CoreWLAN; connecting and power changes use `networksetup`. These were not exercised
  on a real network during development. If macOS refuses, use Wi-Fi Settings.
