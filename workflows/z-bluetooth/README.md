# Bluetooth for Alfred 6

Paired Bluetooth devices with connection controls and battery levels, in a native Alfred window.

Requires macOS, Alfred 6 with Powerpack and Node.js 22+ or Bun.

## Open

Type `bluetooth`, or choose Bluetooth in `dev`. Devices are listed connected first, with device type
and any battery levels macOS reports (case, left, right, device) at the right of each row. Filter
**All**, **Connected** or **Disconnected**.

## Actions

- **↩** connects or disconnects the selected device.
- **⌘K**: connect/disconnect, Copy MAC Address, Copy Device Data, Refresh, Pause/Resume refresh,
  Bluetooth Settings and Workflow Configuration.
- **Back** (Hyper+B) returns one level, or to the Dev launcher with its previous search and selection.

## How it works

- Device details come from the full `system_profiler` report: the short report omits device
  addresses on current macOS. Devices whose address macOS restricts stay visible, with connection
  actions disabled.
- Connection requests use IOBluetooth. If `blueutil` is already installed it handles them instead;
  you can set its path. Nothing is installed automatically.
- macOS may ask for Bluetooth permission. Failed or timed-out requests show an error.
- Battery levels are shown only when macOS reports them, never estimated.
- Details refresh every 10 seconds while the window is open (2–60 seconds, or pause in ⌘K).
- There is no radio power toggle or pairing here; use Bluetooth Settings for those.
