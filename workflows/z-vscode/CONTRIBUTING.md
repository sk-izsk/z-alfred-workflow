# Contributing

1. `bun install`, then `bun run build && bun run link` to load your checkout into Alfred.
2. Make the change (see [AGENTS.md](AGENTS.md) for conventions), rebuild and try it in Alfred.
3. `bun run check` must pass. Add a test for new logic.
4. Open a pull request describing what you changed and how you tried it.

Bugs: include your Alfred version, the editor you picked, and what the footer said.
