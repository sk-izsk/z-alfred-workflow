# LeetCode for Alfred 6

Search and preview LeetCode problems, open the daily challenge, pick a random problem and look up a
profile, in a native Alfred window. A port of the
[Raycast LeetCode extension](https://www.raycast.com/justin0u0/leetcode).

Requires macOS, Alfred 6 with Powerpack, Node.js 22+ or Bun and an internet connection. No LeetCode
account or sign-in is needed.

## Search Problems (`leetcode`)

Type to search; pick a category above the list (All, Algorithms, Database, Shell, Concurrency,
JavaScript, pandas). Each row shows the number and title, the acceptance rate, a lock for premium
problems, the zerotrac community rating and the difficulty. **Load more problems…** at the end fetches
the next 50.

- **↩** previews the problem.
- **⌘K**: Preview, Open in Browser, Copy Link, Daily Challenge, Random Problem…, User Profile…,
  Refresh and Configuration.

## Problem preview

The description as formatted text with its date (daily challenge), difficulty, likes, dislikes and
rating above, and accepted, submissions and acceptance rate below. Premium problems show a notice
instead of the description.

- **↩** opens the problem in your browser.
- **⌘K**: Open in Browser, Copy Link, Copy Problem (Markdown), **Copy Code Template** (every language
  LeetCode offers, your preferred one first ⭐), and Pick Another for random problems.
- **Back** returns to the list with the same search and selection.

## Daily Challenge (`leetdaily`) and Random Problem (`leetrandom`)

`leetdaily` opens today's problem. `leetrandom` picks a random problem with your last filters;
**Random Problem…** in ⌘K sets the category, difficulty, topic and whether to skip premium problems.
⌘R picks another.

## User Profile (`leetuser`)

`leetuser name`, or set **Username** in Configuration. Shows solved counts by difficulty, ranking,
reputation, streak, contest rating, badges, links and the latest accepted problems; ↩ on a problem
previews it.

Back (Hyper+B) from the first screen returns to the Dev launcher when opened there.

## Development

```sh
bun install --frozen-lockfile
bun run check
bun run package
bun run link
```

Tests replace the network. Width, Back and footer follow [UI_CONVENTIONS.md](../../UI_CONVENTIONS.md).

## Differences from Raycast

The menu-bar daily-challenge timer is not included (this repository has no menu-bar features). The
user profile and recent submissions are one screen.
